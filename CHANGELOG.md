# Changelog

## 0.1.0 - 2026-11-21

- Convert default layer masks into clipping shapes and hide the mask source's paints.
- `--disable-mask ARTBOARD`, `--bind-solid ARTBOARD RRGGBB`, `--scan` and `--check`.
- Property kind table generated from rive-runtime `04f53a2a`, read from both the base headers and `CoreRegistry::propertyFieldId`.
- `--bind-solid` no longer fails when the matching colour is the last object in the file.
